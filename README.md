# 🏒 Hockeys UI

A modern, responsive landing page for a fictional professional hockey club. This project was built to practice responsive web design, Tailwind CSS, component-based styling with DaisyUI, and clean UI implementation.

## 🌐 Live Website

**[View Live Demo](https://nazmussakib-dev.github.io/hockeys-ui/)**

## ✨ Features

* 📱 Fully responsive design
* 🏒 Professional hockey club hero section
* 📊 Club statistics and achievements
* 🏆 Hockey programs section
* 🛍️ Product showcase
* 💬 Client/testimonial section
* ❓ Frequently Asked Questions (FAQ)
* 📩 Contact form
* 🦾 Responsive navigation bar
* 🎨 Modern UI with Tailwind CSS and DaisyUI

## 🛠️ Technologies Used

* **HTML5**
* **Tailwind CSS**
* **DaisyUI**
* **JavaScript**
* **CSS**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/nazmussakib-dev/hockeys-ui.git
```

Navigate to the project directory:

```bash
cd hockeys-ui
```

Then open `index.html` in your browser.
